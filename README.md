# Supplementary Repository for Cook et al., 2026: "Modeling Globular Cluster Stellar Streams with a Basis-Expansion N-body Code"

A copy of our conda environment is available via a YAML file. The .ipynb file uses data-loading methods to display stream models produced by KRIOS, NBODY6++GPU (Wang et al., 2015), and particle spray (Price-Whelan (2022), Chen et al. (2025))
